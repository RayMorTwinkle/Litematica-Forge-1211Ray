# 半透明渲染（Translucent Rendering）实现分析

## 概述

半透明渲染（幽灵方块模式）不是一套独立的渲染路径，而是通过**"将所有方块强制路由到 Translucent 层 + 设置全局 shader alpha + 按相机距离反向排序"**三条策略叠加实现的。

## 实现原理（五层架构）

### 第一层：入口 — Mixin 注入 Minecraft 渲染管线

`MixinWorldRenderer.java` 通过 `@Inject` 钩入 `WorldRenderer.renderLayer()`：

```
Minecraft 渲染 Solid 层       → LitematicaRenderer.piecewiseRenderSolid()
Minecraft 渲染 CutoutMipped   → LitematicaRenderer.piecewiseRenderCutoutMipped()
Minecraft 渲染 Cutout         → LitematicaRenderer.piecewiseRenderCutout()
Minecraft 渲染 Translucent    → LitematicaRenderer.piecewiseRenderTranslucent()
                                 LitematicaRenderer.piecewiseRenderOverlay()
```

每个 `piecewiseRender*` 最终调用 `WorldRendererSchematic.renderBlockLayer()`。

### 第二层：核心 — 层渲染与半透明判断

`WorldRendererSchematic.renderBlockLayer()` (第 427-568 行)：

```java
boolean isTranslucent = renderLayer == RenderLayer.getTranslucent();
// 半透明层从远到近渲染（反向遍历区块列表）
boolean reverse = isTranslucent;
```

- 检测当前层是否是 `RenderLayer.getTranslucent()`
- 半透明层**反向遍历**（远→近），保证 alpha 混合顺序正确
- 相机移动超过 1 格时触发深度重新排序

### 第三层：幽灵方块模式 — 全局 Alpha 混合

```java
boolean renderAsTranslucent = Configs.Visuals.RENDER_BLOCKS_AS_TRANSLUCENT.getBooleanValue();
if (renderAsTranslucent) {
    float alpha = (float) Configs.Visuals.GHOST_BLOCK_ALPHA.getDoubleValue();
    RenderSystem.setShaderColor(1.0f, 1.0f, 1.0f, alpha);  // 设置全局 alpha
}
// ... 渲染所有区块 ...
if (renderAsTranslucent) {
    RenderSystem.setShaderColor(1.0f, 1.0f, 1.0f, 1.0f);  // 恢复
}
```

通过 `RenderSystem.setShaderColor()` 统一控制所有方块的透明度。

### 第四层：VBO 构建 — 方块数据路由

`ChunkRendererSchematicVbo` 构建 VBO 时决定方块数据去向：

```java
boolean translucent = Configs.Visuals.RENDER_BLOCKS_AS_TRANSLUCENT.getBooleanValue();
RenderLayer layer = translucent 
    ? RenderLayer.getTranslucent()           // 全部分配到半透明层
    : RenderLayers.getBlockLayer(state);      // 按材质属性分配
```

- **开启半透明模式** → 所有方块强制路由到 `Translucent` 层
- **关闭半透明模式** → 方块按其材质属性路由到对应层

### 第五层：深度排序

`ChunkRendererSchematicVbo.resortTransparency()` (第 209-261 行)：

```
for each chunk:
  if renderEnableTranslucentResorting:
    1. 取 translucent 层的已构建 BufferBuilder 数据
    2. 使用 VertexSorter.byDistance(x, y, z) 按相机距离排序
    3. 重新上传排序后的索引缓冲到 GPU
```

`VertexSorter.byDistance()` 按顶点到相机的欧氏距离排序，离相机远的先绘制，近的后绘制。

## 渲染流程图

```
Minecraft 帧渲染
│
├─ WorldRenderer.setupTerrain()
│    └─ Mixin → piecewisePrepareAndUpdate()
│         ├─ setupTerrain() 设置可见区块
│         └─ updateChunks() 上传 VBO 数据
│
├─ WorldRenderer.renderLayer(Solid)
│    └─ Mixin → piecewiseRenderSolid()
│         └─ WorldRendererSchematic.renderBlockLayer(Solid)
│              ├─ 正向遍历区块
│              ├─ if renderBlocksAsTranslucent: setShaderColor(1,1,1,0.5)
│              └─ 绘制 VBO
│
├─ WorldRenderer.renderLayer(CutoutMipped)
│    └─ Mixin → piecewiseRenderCutoutMipped()
│         └─ ...同上...
│
├─ WorldRenderer.renderLayer(Cutout)
│    └─ Mixin → piecewiseRenderCutout()
│         └─ ...同上...
│
└─ WorldRenderer.renderLayer(Translucent)
     └─ Mixin → piecewiseRenderTranslucent()
          └─ WorldRendererSchematic.renderBlockLayer(Translucent)
               ├─ 相机移动 > 1 格 → 触发深度重新排序
               ├─ 反向遍历区块（远→近）
               ├─ setShaderColor(1,1,1,alpha)
               ├─ 绘制 VBO
               └─ 恢复 shader color
     └─ Mixin → piecewiseRenderOverlay()
          └─ renderBlockOverlays(OUTLINE + QUAD)
```

## OverlayRenderType 枚举

```java
public enum OverlayRenderType {
    OUTLINE(DEBUG_LINES, ..., false, false),  // translucent=false → 不透明线条
    QUAD   (QUADS,       ..., false, true);   // translucent=true  → 半透明面片
}
```

`QUAD` 类型标记为半透明，在 Overlay 渲染时参与深度排序；`OUTLINE` 类型不参与。

## 总结

| 关键机制 | 实现方式 |
|----------|----------|
| 方块路由 | 开启半透明后，所有方块强制写入 `Translucent` 层 |
| Alpha 控制 | `RenderSystem.setShaderColor()` 设置全局 alpha |
| 渲染顺序 | 半透明层反向遍历区块（远→近） |
| 深度排序 | `VertexSorter.byDistance()` 按相机距离重排顶点索引 |
| 触发条件 | 相机移动距离 > 1 格时重新排序 |
