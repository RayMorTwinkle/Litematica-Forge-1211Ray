# 半透明滑动条 — 主菜单集成方案

## 目标

在 `GuiMainMenu` 主菜单中直接放置一个滑动条，无需进入配置页面即可调整 `ghostBlockAlpha`（幽灵方块透明度）。

## 可行性

✅ mafglib 已提供所需组件：

| 组件 | 位置 |
|------|------|
| `WidgetSlider` | `fi.dy.masa.malilib.gui.widgets.WidgetSlider` |
| `SliderCallbackDouble` | `fi.dy.masa.malilib.config.gui.SliderCallbackDouble` |
| `ISliderCallback` | `fi.dy.masa.malilib.gui.interfaces.ISliderCallback` |
| `GuiBase.addWidget()` | `fi.dy.masa.malilib.gui.GuiBase` |
| `GuiBase.addLabel()` | `fi.dy.masa.malilib.gui.GuiBase` |

✅ `Configs.Visuals.GHOST_BLOCK_ALPHA` 是 `ConfigDouble`，已实现 `IConfigDouble` 接口。

## 需要修改的文件

### 1. `src/main/java/fi/dy/masa/litematica/gui/GuiMainMenu.java`

**新增 import**:

```java
import fi.dy.masa.malilib.config.gui.SliderCallbackDouble;
import fi.dy.masa.malilib.gui.widgets.WidgetSlider;
```

**在 `initGui()` 方法末尾（第73行后）添加**:

```java
// === 幽灵方块透明度滑动条 ===
y += 28;

String alphaLabel = StringUtils.translate("litematica.gui.label.ghost_block_alpha");
int labelWidth = this.getStringWidth(alphaLabel) + 20;
this.addLabel(x, y, labelWidth, 12, 0xFFAAAAAA, alphaLabel);

y += 14;
SliderCallbackDouble alphaCallback = new SliderCallbackDouble(
    Configs.Visuals.GHOST_BLOCK_ALPHA, null);
WidgetSlider alphaSlider = new WidgetSlider(x, y, width, 20, alphaCallback);
this.addWidget(alphaSlider);
```

### 2. 语言文件

**`src/main/resources/assets/litematica/lang/en_us.json`** — 新增条目:

## 工作原理

```
用户拖动滑动条
  → WidgetSlider.onMouseClickedImpl() / render()
    → SliderCallbackDouble.setValueRelative(relValue)
      → ConfigDouble.setDoubleValue(newValue)    // 写入配置
      → malilib 框架自动持久化到 forgematica.json
```

`SliderCallbackDouble` 内部实现:

```java
// getValueRelative() — 滑动条位置 = (当前值 - 最小值) / (最大值 - 最小值)
// setValueRelative() — 反向计算并写入配置

// getFormattedDisplayValue() — 显示 "0.5000" 格式
```

滑动条范围自动匹配 `GHOST_BLOCK_ALPHA` 的定义范围 `[0, 1]`。

---

## 注意事项

- `renderBlocksAsTranslucent` 必须设为 `true` 才会生效（可在主菜单上也加一个开关，但本次方案聚焦滑动条）
- `SliderCallbackDouble` 构造器的第二个参数是可选的 `resetButton`，传 `null` 即可
- 滑动条宽度与现有按钮宽度一致（由 `getButtonWidth()` 决定），视觉统一
- 配置值实时生效，无需重启游戏
